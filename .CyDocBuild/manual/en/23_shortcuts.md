Shortcuts depend on context. Text fields, popups, graphs and transform sessions can own keys. Layer Transform reuses W/E/R/P for its modes.

## Documents {#documents}

- F1: help for the focused panel or selected node; available without a document and while typing.
- Ctrl+N: new; Ctrl+O: open; Ctrl+Shift+O: import as layer.
- Ctrl+S / Ctrl+Shift+S: save / save as; Ctrl+W: close.
- Ctrl+Alt+Shift+W: export image.
- Ctrl+Z: undo; Ctrl+Shift+Z or Ctrl+Y: redo.
- Ctrl+C / Ctrl+X / Ctrl+V: copy / cut / paste.

## Layers and geometry {#layers-and-geometry}

- Ctrl+Shift+N: new pixel layer.
- Ctrl+J: duplicate, or layer via copy with a selection.
- Ctrl+E / Ctrl+Shift+E: merge down / merge visible.
- Ctrl+G / Ctrl+Shift+G: group / ungroup; Ctrl+Alt+G: clipping.
- Ctrl+T: Free Transform; Enter/Escape: commit/cancel.
- Ctrl+Alt+I / Ctrl+Alt+C: image size / canvas size.
- Arrow keys: nudge supported target; Shift increases step.

## Selection and view {#selection-and-view}

- Ctrl+A / Ctrl+D / Ctrl+Shift+D: select all / deselect / reselect.
- Ctrl+Shift+I: invert; Shift+F6: feather; Q: Quick Mask.
- Ctrl+0 / Ctrl+1: fit / 100%.
- Ctrl+Alt+1 / 2 / 3: final / selected layer / up to selected layer.
- Ctrl+R: rulers; Ctrl+;: guides; Ctrl+Shift+;: snapping; Ctrl+': grid.
- Space: temporary hand; Tab/Shift+Tab: hide bottom/right area.
- Alt+1 through Alt+7: right-column group; F11: expand hovered panel.

## Tools and fields {#tools-and-fields}

- B: Brush; E: Eraser; V: Move; A: Layer Transform.
- M/Shift+M: Rectangle/Ellipse; L: Lasso/Magnetic; Shift+L: Polygonal.
- W/Shift+W: Quick Selection/Magic Wand; C: Crop outside graph.
- T: Text; U: Shape; P: Pen; S: Clone; J: healing family.
- G: Gradient; K: Bucket; I: Picker; H: Hand; Z: Zoom.
- [ / ]: brush size; X: swap colors; D: default colors.
- Double-click/Ctrl+click number: type; Enter/Escape/Tab: confirm/cancel/advance.
