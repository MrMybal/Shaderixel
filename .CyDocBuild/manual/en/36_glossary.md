- Alpha / coverage: how much a pixel contributes to a composite.
- Bake to Pixel Layer: replace one rendered 2D layer with paintable pixels.
- Graph Bake: retain a computed image in an execution tool.
- Mesh bake: derive maps from geometry and UVs.
- Draw: a shader generator that does not need an input image.
- Effect graph: per-pixel calculation compiled into one shader.
- Image graph: composition of images, effects, values and actions.
- Halo: neighboring pixel support needed for correct tiled rendering.
- Live: reevaluate when inputs change.
- Retained result: stored action output, regenerated by explicit execution.
- PBR: material channels intended for physically based rendering.
- ORM: occlusion in red, roughness in green, metalness in blue.
- SDF: signed-distance field, including negative values.
- UV field: image containing sample coordinates rather than ordinary colors.
- Nine-slice: preserve corners while stretching/repeating edges and center.
- Eight-slice: a nine-slice border with a transparent center.
- Smart object: reusable 2D source with separate instance placement.
- Smart material: reusable 3D fill/mask assembly.
- Template: starting document; function: reusable graph node.

## What this manual covers {#what-this-manual-covers}

The handbook covers the editor's current user workflows and links to the generated shipped effect/function reference. Reference defaults do not represent document overrides. Preset names and stable IDs remain searchable in their original form, including when explanations are translated.

The two language editions use the same chapter identities, so changing language keeps the current subject. Unsupported interface languages fall back to English. User-added presets are outside the shipped reference.

For the detailed source schemas use the repository preset/plugin guides. For a failure, use the troubleshooting chapter and report a minimal reproducible case.
