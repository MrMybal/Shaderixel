ComfyUI requires a running external server. Configure its endpoint and model/checkpoint in AI settings. A preset does not install the server, models or custom nodes.

## Assistant and image providers {#assistant-and-image-providers}

The AI panel separates assistant/bridge settings from image-generation settings. Image providers include the configured OpenAI-compatible service, Gemini and ComfyUI paths. Select the intended provider, endpoint and model/checkpoint before running a request. Provider support and required credentials depend on that configuration; a local preset does not supply an account or download models.

The local bridge, assistant conversation and image-processing tools have different roles. A running bridge does not prove the selected image provider is reachable. For a reproducible local graph, use ordinary image effects and explicit inputs; AI results are retained after execution.

## Image to image {#image-to-image}

ComfyUI Texture Image to Image runs on Process Texture. An empty workflow uses the built-in image-to-image pipeline and configured checkpoint, prompt and denoise.

For custom workflows, export JSON in ComfyUI API format. Required nodes/models must already exist on the server. Shaderixel applies supported substitutions only; denoise can remain the custom workflow's saved value.

## Depth and PBR workflows {#depth-and-pbr-workflows}

ComfyUI Depth to Surface Maps and ComfyUI PBR Map Workflow need a supplied API workflow. An empty path reports a message instead of running a specialized model.

Use LoadImage input and a single SaveImage for the desired map. Shaderixel retrieves the first generated image. Use separate instances/workflows for independent maps.

An unexecuted action previews its input. A visible photo is not yet AI depth or a computed PBR map. Trigger the event, wait and inspect the retained result.

## Upscaling and connection issues {#upscaling-and-connection-issues}

Textures Upscale and Export defaults to local bicubic. Enable Use ComfyUI for AI and enter the exact installed filename from models/upscale_models.

Export keeps full enlarged resolution; graph output fits the document. AI can invent detail and alter numeric maps, so preserve data using dedicated processing.

For failures, check server availability, endpoint, model, API JSON and custom nodes. Read status messages and test the workflow in ComfyUI itself.
