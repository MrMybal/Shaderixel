Shaderixel is an image editor with layer and node workflows, photo processing, texture tools and 3D painting.

Shaderixel is distributed under GPL-3.0-or-later, except where a separate license is specified. Read the [full application license](assets/legal/Shaderixel.txt). The standalone Unreal connector is separately MIT-licensed; Unreal Engine remains governed by Epic’s terms.

## Reader and dependencies {#reader}

The documentation uses CyDoc under the [MIT license](assets/legal/CyDoc.txt). Other reader dependencies retain their own notices under the documentation assets. These library licenses do not change Shaderixel’s application license.
