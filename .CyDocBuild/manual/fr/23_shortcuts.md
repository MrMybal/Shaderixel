Le contexte détermine les raccourcis. Champs, fenêtres contextuelles, graphes et transformations peuvent utiliser les mêmes touches. Transformation de calque réemploie W/E/R/P pour ses modes.

## Documents {#documents}

- F1 : aide du panneau actif ou du nœud sélectionné, même sans document ou pendant une saisie.
- Ctrl+N : nouveau ; Ctrl+O : ouvrir ; Ctrl+Maj+O : importer comme calque.
- Ctrl+S / Ctrl+Maj+S : enregistrer / enregistrer sous ; Ctrl+W : fermer.
- Ctrl+Alt+Maj+W : exporter.
- Ctrl+Z : annuler ; Ctrl+Maj+Z ou Ctrl+Y : rétablir.
- Ctrl+C / Ctrl+X / Ctrl+V : copier / couper / coller.

## Calques et géométrie {#layers-and-geometry}

- Ctrl+Maj+N : calque de pixels.
- Ctrl+J : dupliquer, ou calque par copie avec une sélection.
- Ctrl+E / Ctrl+Maj+E : fusionner vers le bas / visibles.
- Ctrl+G / Ctrl+Maj+G : grouper / dissocier ; Ctrl+Alt+G : écrêtage.
- Ctrl+T : transformation ; Entrée/Échap : valider/annuler.
- Ctrl+Alt+I / Ctrl+Alt+C : taille d'image / canevas.
- Flèches : déplacer une cible compatible ; Maj augmente le pas.

## Sélection et vue {#selection-and-view}

- Ctrl+A / Ctrl+D / Ctrl+Maj+D : tout sélectionner / désélectionner / resélectionner.
- Ctrl+Maj+I : inverser ; Maj+F6 : contour progressif ; Q : masque rapide.
- Ctrl+0 / Ctrl+1 : adapter / 100 %.
- Ctrl+Alt+1 / 2 / 3 : final / calque seul / jusqu'au calque.
- Ctrl+R : règles ; Ctrl+; : repères ; Ctrl+Maj+; : magnétisme ; Ctrl+' : grille.
- Espace : main temporaire ; Tab/Maj+Tab : masquer bas/droite.
- Alt+1 à Alt+7 : groupe latéral ; F11 : agrandir le panneau survolé.

## Outils et valeurs {#tools-and-fields}

- B : pinceau ; E : gomme ; V : déplacement ; A : transformation de calque.
- M/Maj+M : rectangle/ellipse ; L : lasso/magnétique ; Maj+L : polygonal.
- W/Maj+W : sélection rapide/baguette ; C : recadrage hors graphe.
- T : texte ; U : forme ; P : plume ; S : tampon ; J : correction.
- G : dégradé ; K : pot ; I : pipette ; H : main ; Z : zoom.
- [ / ] : taille ; X : échanger couleurs ; D : couleurs initiales.
- Double-clic/Ctrl+clic : saisir ; Entrée/Échap/Tab : valider/annuler/suivant.
