# IA, ComfyUI et agrandissement

ComfyUI exige un serveur externe démarré. Configurez son adresse et le modèle/checkpoint dans les réglages IA. Un preset n'installe ni serveur, ni modèle, ni nœud personnalisé.

## Assistant et fournisseurs d'images

Le panneau IA distingue assistant/pont et génération d'images. Les chemins disponibles comprennent le service compatible OpenAI configuré, Gemini et ComfyUI. Choisissez fournisseur, adresse et modèle/checkpoint avant une requête. Les identifiants requis dépendent de cette configuration ; un preset ne fournit pas de compte et ne télécharge pas les modèles.

Pont local, conversation et outils de traitement ont des rôles différents. Un pont actif ne prouve pas l'accès au fournisseur d'images. Pour un graphe local reproductible, utilisez effets classiques et entrées explicites ; les résultats IA sont conservés après exécution.

## Image vers image

ComfyUI Texture Image to Image s'exécute avec Process Texture. Un workflow vide emploie la chaîne intégrée avec checkpoint, prompt et débruitage configurés.

Pour un workflow personnalisé, exportez le JSON au format API de ComfyUI. Les nœuds et modèles doivent exister sur le serveur. Seules les substitutions prises en charge s'appliquent ; le débruitage peut garder sa valeur enregistrée dans le workflow.

## Profondeur et cartes PBR

ComfyUI Depth to Surface Maps et ComfyUI PBR Map Workflow nécessitent un workflow API fourni. Un chemin vide affiche un message plutôt que lancer un modèle spécialisé.

Utilisez LoadImage et un seul SaveImage pour la carte attendue. Shaderixel récupère la première image générée ; employez plusieurs instances/workflows pour plusieurs cartes.

Avant exécution, une action affiche son entrée. Une photo visible n'est donc pas une profondeur IA calculée. Lancez l'événement, attendez et inspectez le résultat conservé.

## Agrandir et diagnostiquer

Textures Upscale and Export emploie le bicubique local par défaut. Activez Use ComfyUI pour l'IA et donnez le nom exact du modèle installé dans models/upscale_models.

L'export garde toute la résolution agrandie ; le graphe l'adapte au document. L'IA peut inventer des détails et modifier les valeurs des cartes ; traitez les données avec les outils appropriés.

En cas d'échec, vérifiez serveur, adresse, modèle, JSON API et nœuds, lisez le message et testez le workflow dans ComfyUI.
