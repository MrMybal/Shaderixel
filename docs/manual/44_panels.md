# Panel and dialog directory

This directory covers every panel in Window > Panels and the application's directly named user dialogs. Each entry explains its role and links to the corresponding workflow. F1 follows the focused panel, with more specific references for selected tools, nodes, brushes and action steps.

Use Window to reopen a panel, select its right-side group, and clear its filter if controls appear missing. A modal operation may need to finish or be canceled before returning to the rest of the editor. Help > Documentation resumes the last article without starting an operation.

The directory is checked against the application panel menu and directly named windows during manual generation. Adding a panel without registering help fails that check.
