Shaderixel · version de test

Éditeur d'images entièrement GPU : calques façon Photoshop, mode nodal, effets HLSL/Slang codables, peinture 3D PBR et pont IA (MCP). Version du {{DATE}}.

Démarrer

Lancer

  1. Décompressez l'archive où vous voulez (le dossier est autonome).
  2. Lancez Shaderixel.exe (Direct3D 12).
  3. Variante Vulkan : Lancer Shaderixel (Vulkan).bat ou ShaderixelVk.exe.
  4. Ouvrez un exemple : Ctrl+O → dossier Exemples, ou glissez un fichier sur la fenêtre.

Configuration requise

  • Windows 10 / 11 64 bits.
  • Carte graphique Direct3D 12 (niveau 12_0) ; Vulkan 1.3 pour la variante Vulkan.
  • Premier lancement : les shaders se compilent (quelques secondes), ensuite ils sont en cache.
  • Réglages et disposition sont enregistrés à côté de l'exécutable.

Parcours conseillé (15 minutes)

1. Retouche classique

  1. Fichier > Nouveau (Ctrl+N), pinceau (B), taille avec [ ].
  2. Nouveau calque (Ctrl+Maj+N), sélection rectangulaire (M), remplir (Alt+Retour).
  3. Transformation (Ctrl+T), Entrée pour valider ; annuler Ctrl+Z.
  4. Filtre > Flou gaussien : le filtre reste modifiable dans Propriétés.

2. Mode nodal et effets

  1. Ouvrez 05_Mode_nodal.sxl, panneau Graphe en bas.
  2. Clic droit dans le graphe : ajoutez un effet, reliez-le.
  3. Tirez un lien depuis une broche et lâchez-le dans le vide : le nœud choisi est relié par sa première broche du bon type. Mini-carte en bas à droite (clic ou glisser pour s'y rendre, M pour la masquer). Relais : double-clic sur un lien pour y poser un point de passage (images, valeurs ou exécution), à déplacer pour ranger les liens ; aussi dans le menu des nœuds (Organisation).
  4. Sélectionnez le nœud HLSL et modifiez son code, Ctrl+Entrée.
  5. Ouvrez 06_Graphe_d_effet.sxl : onglet Éditeur d'effets.

3. Peinture 3D (façon Substance)

  1. Nouveau document carré (1024 × 1024), onglet 3D à droite, bouton « Espace peinture 3D » : vue 3D à gauche, texture à droite.
  2. Cliquez un matériau de l'étagère (Or, Rouille...) : un calque de matériau est créé, masque noir.
  3. Pinceau (B) sur le modèle : le masque se peint en blanc et applique couleur, rugosité, métal et hauteur en même temps.
  4. Réglez les canaux du matériau dans « Propriétés du matériau » ; HDRI... → Ciel.hdr, puis « Exporter les textures PBR... ».

Espace de travail

  1. Colonne de droite en onglets : Général, Outils, Effets, Fusion, Peinture, 3D, IA (Alt+1...7).
  2. Tab masque la zone du graphe, Maj+Tab la colonne de droite (boutons aussi dans la barre d'état).
  3. Fenêtre > Nouvelle fenêtre : une fenêtre à placer sur un autre écran, glissez-y des panneaux par leur onglet ; tout panneau peut aussi sortir de la fenêtre principale.
  4. Fenêtre > Dispositions : enregistrer / recharger vos dispositions.

Transformer un calque (outil Transformation, A)

  1. Déplacer / Rotation / Échelle / Pivot (W E R P dans l'outil) : glissez dans le cadre, sur les flèches ou les poignées. Maj plus rapide, Ctrl plus lent.
  2. Barre en haut à droite du canevas : grilles d'aimantation pour chaque mode (préréglages, valeur libre, ou « libre » sans grille), repère Monde / Local, flèches, aperçu du dépassement, ratio verrouillé.
  3. Sans perte : l'image entière est conservée (calque pixel converti en objet dynamique), ce qui dépasse du document reste visible pendant la manipulation. « Rogner au document » si vous voulez couper.
  4. Calques Draw (remplissage, texte, forme) : un filtre Transform non destructif est ajouté. En mode nodal : un nœud Transform après le nœud actif, pour transformer une entrée avant sa fusion.
  5. Propriétés d'un calque image : transformation en valeurs (position, échelle, rotation, pivot, miroirs, centrer, ajuster), filtrage (bicubique, bilinéaire, plus proche) et « Réglages de l'image » (exposition, contraste, gamma, saturation, teinte, température...).

Types de nœuds et sous-graphes

  1. Chaque nœud du graphe porte son type : IMAGE (pixels), DRAW (dessiné par un shader), BLEND (fusion), EFFECT (entrée → sortie), TOOL (outils du graphe : Transform, d'autres suivront), SUBGRAPH (graphe à l'intérieur : groupe, document), CANAUX, SORTIE.
  2. SubGraph : glissez un .sxl ou .sx3d sur le graphe, le canevas ou les calques (ou Calque > Objet dynamique depuis un fichier) : la sortie de son graphe devient l'image d'un objet dynamique, transformable. Lié : suit le fichier (« Mettre à jour ») ; incorporé : « Modifier le contenu » ouvre son graphe.

Outils du graphe : Bake, Upscale, ComfyUI

  1. Clic droit dans le graphe > Outils. Bake fige son entrée en pixels : les nœuds avant sont grisés et ne sont plus calculés (graphe plus léger).
  2. PassLive (case du nœud ou clic droit) : l'entrée repasse en direct pour la modifier, le bake est gardé ; puis « Rebaker ».
  3. Upscale : agrandit l'entrée (x2 à x8) en bicubique sur le GPU ou avec un modèle IA via ComfyUI (4x-UltraSharp, RealESRGAN...). Le résultat garde sa pleine résolution : « Exporter l'image... ».
  4. ComfyUI : envoie l'entrée à un workflow (image vers image intégré, ou votre workflow « Save (API format) ») avec un prompt, et utilise le résultat dans le graphe. Serveur réglé dans le panneau IA.
  5. Clic droit > Convertir en image : le nœud devient une image (pixels) du graphe, modifiable au pinceau.

Fonctions : sous-graphes et outils personnalisés

  1. Sélectionnez des nœuds, clic droit > « Créer un sous-graphe / un outil depuis la sélection » : ils sont remplacés par un nœud Fonction ; les liens qui entraient ou sortaient deviennent ses entrées et sorties (autant que nécessaire). Ou clic droit > Fonctions > nouveau sous-graphe / outil.
  2. Double-clic sur le nœud : son graphe s'ouvre dans un onglet (avec l'image reçue en entrée pour l'aperçu, ou l'image de référence si rien n'est relié). Le bandeau du graphe indique où l'on est (Document › Fonction) et « < Retour » revient au graphe parent. Chaque modification met à jour le nœud. Ajoutez des nœuds « Entrée de fonction » / « Sortie de fonction » pour ses broches (champ Ordre pour les trier).
  3. Deux modes : Live (calculé en direct) ou Apply (« Appliquer » garde les sorties en pixels, les nœuds avant sont figés ; « Réappliquer » après un changement).
  4. « Enregistrer dans la bibliothèque » : la fonction apparaît dans le menu des nœuds > Bibliothèque (sous-graphes / outils), réutilisable dans tous les documents.

Valeurs, variables et exécution

  1. Broches typées : Image, Canal, Float, Int, Bool, Vec2, Couleur, Texte, Nom, tableaux (carrés), exécution (flèches blanches). Seuls les types compatibles se relient.
  2. Clic droit > Valeurs / Maths / Logique / Vecteurs / Texte / Tableaux : constantes et opérations. Une entrée valeur non reliée a son champ sur le nœud, comme dans Unreal : glisser horizontalement un nombre (Maj plus vite, Ctrl plus lent), clic pour le taper, clic sur une case à cocher, clic sur une couleur pour le nuancier, clic sur un texte pour l'écrire.
  3. Propriétés d'un effet > « Paramètres en broches » : un paramètre devient une entrée, pilotée par une valeur, une variable ou une entrée de fonction.
  4. Variables (Propriétés sans sélection, ou d'un nœud Variable) : les variables exposées d'une fonction se règlent sur chaque nœud de la fonction.
  5. Exécution : un nœud Événement est un bouton ; il lance les actions reliées (Séquence, Branche, Pour / Pour chaque, Définir une variable, Bake, Upscale, ComfyUI, Exporter en PNG, Message). Les images produites sont gardées : les nœuds avant ne sont plus calculés.
  6. Créer ses propres effets, calques Draw, fusions, sous-graphes et outils : voir PRESETS.md (à côté de Shaderixel.exe).

Trim sheets

  1. Panneau « Trim sheet » (onglet Outils) : un modèle de disposition (architecture, détails, bandes égales, bandes + tuiles), des hauteurs sur mesure (ex. 256, 128, 64, 0) ou une bande entre chaque repère horizontal ; marge entre les bandes.
  2. Outil Trim (avec le recadrage) : glisser un bord pour redimensionner (pas de 8 px, Maj : 1 px, la bande voisine suit), clic pour choisir, double-clic pour sélectionner ses pixels. Chaque trim : nom, rectangle, raccord H / V, découpage en colonnes (tuiles).
  3. « Rendre raccordable » : mélange les bords du trim avec son contenu décalé, sur le calque actif, pour une répétition sans couture ; l'aperçu de répétition (avec décalage) montre le raccord. Effet « Raccord de bande (trim) » aussi disponible en filtre.
  4. Sorties : calque ID (une couleur par trim, masqué), aperçu 3D (chaque bande répétée trois fois dans la Vue 3D), disposition exportée en JSON (rectangles et UV en haut/bas à gauche) pour les moteurs et logiciels 3D. La disposition est enregistrée dans le .sxl.

Modèles de documents

  1. Fichier > Nouveau (Ctrl+N) ou « Depuis un modèle... » sur l'écran d'accueil : onglet Modèles, par catégorie (Textures, Trim sheets, Graphisme, Game art, Photo, Nodal) avec recherche et vignettes ; double-clic pour créer. L'onglet « Document vide » garde les tailles prédéfinies.
  2. Un document créé depuis un modèle est nouveau et sans nom : l'enregistrer demande un emplacement, le modèle ne change pas.
  3. Fichier > « Enregistrer comme modèle... » : nom, catégorie, description ; le document entier est gardé (calques, graphe, trims, repères) avec une vignette. Vos modèles (catégorie « Mes modèles » par défaut) se suppriment depuis le dialogue ; « Ouvrir le dossier de mes modèles » pour les copier ou les partager.

Organiser un grand graphe

  1. Cadres de commentaire : sélectionnez des nœuds puis C (ou clic droit > « Commentaire autour de la sélection », ou « + Commentaire ici » dans le menu d'ajout). Glisser le titre déplace le cadre et les nœuds qu'il contient, le coin le redimensionne ; double-clic ou clic droit sur le titre : renommer, couleur, ajuster aux nœuds, supprimer (les nœuds restent).
  2. Ctrl+F dans le graphe : chercher un nœud ou un commentaire (nom, type, opération, effet) et y aller.
  3. Clic droit sur une sélection > Aligner : à gauche, en haut, en colonne, répartir horizontalement ou verticalement. F cadre la sélection (ou tout).

Panneau Ressources (zone du bas)

  1. Onglets Images et Maillages : explorateur de fichiers avec vignettes (les maillages en petit rendu 3D, avec leur nombre de triangles), raccourcis (Bureau, Images, Documents, Téléchargements, Exemples, disques) et la liste « Gardés » : l'étoile d'un fichier ou du dossier courant le garde à portée.
  2. Double-clic : ouvrir (un maillage s'ajoute à la scène de rendu si un projet 3D est actif). Glisser sur le canevas ou les calques : objet dynamique ; sur le graphe : nœud image ; sur la vue Rendu : ajouté à la scène. Clic droit : placer, lier, ajouter au graphe, afficher dans l'Explorateur Windows.
  3. Onglet Lumières et objets : boîte à lumière, débouchage, contre-jour, projecteur, ampoule, lumière du dessus, soleil, néon ; sol, fond cyclo, cube, sphère ; scènes complètes. Clic ou glisser sur la vue Rendu pour composer la scène du projet 3D actif.

Panneau Effets

  1. Les effets sont rangés par familles (Couleur et tons, Flou, Netteté, Déformation, Lumière et glow, Stylisation, Bruit et grain, Glitch et rétro, Textures et PBR, Masques et canaux, Styles de calque, Générateurs, Dessin et formes, Game art) avec leur nombre, plus Favoris (étoile) et Récents.
  2. Filtre de source (Shaderixel / CyTexture) ; « Variantes » montre les variantes et copies de test masquées par défaut. Le menu d'ajout de nœuds suit les mêmes familles. Dans un effet, //@category Famille/Sous-catégorie le range où vous voulez.

Effets, fusions, pinceaux en graphe

  1. Glissez un effet du panneau Effets sur un nœud de calque (filtre), sur un lien (inséré), dans le vide (nouveau nœud), sur un calque ou sur l'image.
  2. Vignettes du panneau Effets : « Aperçu : calque actif », « image entière » ou « référence » (logo sur fond, mire de couleurs, ou votre image avec « Choisir une image... ») pour juger un effet sans dépendre du document.
  3. Onglet Fusion : modes standard et fusions de bibliothèque avec aperçu sur le calque actif ; « Nouvelle (graphe) » ouvre l'éditeur visuel (A dessous, B calque, masque).
  4. Effet en HLSL : Fichier > Importer un effet HLSL (ou déposez un .hlsl, ou Éditeur d'effets > « Importer du HLSL... ») ; entrées et sorties créées depuis la fonction ou les annotations //@in //@out. Pour une IA : skill IA/skills/shaderixel-hlsl-effect et outil MCP shaderixel.effect_from_hlsl.
  5. Tablette graphique : Options > Tablette (Windows Ink ou Wintab, courbe de pression). Les pinceaux reçoivent la pression, l'inclinaison, la rotation du stylet et la vitesse ; réglez les réactions dans l'éditeur de pinceau et essayez-les dans sa zone d'essai. Le pinceau « Texture » (Formes) utilise une image : choisissez-la dans ses réglages.
  6. Onglet Peinture : pinceaux en code ou « Nouveau (graphe) » ; l'éditeur visuel règle aussi le placement (espacement, aérographe, suivre le trait, dispersion, aléas).

Mode Paint 3D (texturer un modèle)

  1. Fichier > Nouveau projet Paint 3D : maillage (sphère, cube, plan ou OBJ / glTF avec UV), résolution, canaux, modèle d'export, matériau de base. Le projet (.sx3d) a son propre espace de travail.
  2. Onglet 3D : Calques 3D (« + Peinture » peint plusieurs canaux d'un coup, « + Matériau » ajoute un matériau à masque) et Matériau du pinceau (canaux cochés et leurs valeurs, préréglages).
  3. Outil Projection : choisissez une image, puis cliquez sur le modèle (Ctrl+molette : taille, Maj+molette : rotation). Symétrie X, Y ou Z dans Calques 3D.
  4. Vue 3D > « Exporter les textures... » : séparées, Unreal (BaseColor, Normal, ORM) ou Unity HDRP (BaseMap, Normal, MaskMap).

Paint 3D : pinceaux et outils

  1. Matériau du pinceau > Pinceau 3D : la pointe de n'importe quel pinceau de la bibliothèque est projetée sur le modèle (avec ses variantes), dont 15 pinceaux « Texture 3D » : usure écaillée, éclaboussures, rouille, coulures, fissures, saleté, rivets, couture, pinceau sec, rayures...
  2. Dynamique : angle, suivre le trait, variations d'angle / de taille / de flux, dispersion. Trait : lissage au fil (lazy mouse), angle limite (faces de biais), Maj+clic pour une ligne droite depuis la fin du trait précédent.
  3. Outil Remplissage par polygone (clic droit sur l'outil Projection) : remplit le triangle, la face plate, l'île UV, la pièce ou tout le modèle sous le curseur (surligné au survol) avec le matériau du pinceau ; Ctrl+clic efface.

Rechercher partout

  1. Champ « Rechercher partout » dans la barre de menus (Ctrl+Maj+F) : tous les menus et sous-menus, toutes les fenêtres et onglets, et les propriétés et boutons des panneaux. Plusieurs mots, sans accents nécessaires (« pression taille », « opacite »).
  2. Résultats groupés (menus, fenêtres et onglets, propriétés et boutons) avec leur emplacement ; ↑ ↓ puis Entrée, ou un clic : un menu est exécuté (ses sous-menus s'ouvrent seuls), une fenêtre passe devant (son onglet de colonne s'affiche, un panneau fermé se rouvre), une propriété est amenée à l'écran et clignote.
  3. Les contenus aussi : effets (ajoutés en filtre au calque actif), pinceaux (choisis), matériaux intelligents (appliqués au projet 3D), fonctions et outils de la bibliothèque (ajoutés au graphe). Champ vide : les résultats récents.
  4. « Surligner dans les panneaux » : pendant la saisie, les propriétés visibles qui correspondent sont entourées dans toutes les fenêtres.
  5. L'index se construit une fois après chaque mise à jour de Shaderixel (quelques secondes au démarrage : les menus s'ouvrent invisibles, les onglets défilent) puis se complète tout seul ; il est gardé d'une session à l'autre.

Plugins

  1. Menu Plugins : les commandes, fenêtres (Plugins > Fenêtres) et outils (Plugins > Outils, et en bas de la barre d'outils) ajoutés par les plugins.
  2. Livrés en exemple : Exemple (C++) (Plugins > Exemple > Dire bonjour, fenêtre « Exemple de plugin », outil Étoile : un clic peint une étoile avec aperçu au survol, aussi sur le modèle dans la Vue 3D ; Plugins > Exemple > Inverser les couleurs du calque, par l'accès aux pixels) et Exemple (script Python) (lister les calques, ajouter un calque bleu, et la fenêtre Grille écrite en Python : Plugins > Fenêtres > Grille).
  3. Palette (plugin livré) : Plugins > Fenêtres > Palette, « Extraire » : les couleurs dominantes du calque actif ; clic : couleur du pinceau, clic droit : arrière-plan ; « Auto » suit les modifications.
  4. Gestionnaire : « Installer depuis un .zip... » (ou glisser le .zip sur la fenêtre), « Créer un plugin... » (squelette Python fenêtre / commande ou C++), « Rechargement automatique » pour les développeurs.
  5. Plugins > Gestionnaire de plugins... : activer / désactiver, recharger une DLL recompilée sans redémarrer, rechercher les nouveaux, ouvrir le dossier utilisateur (%LOCALAPPDATA%\Shaderixel\Plugins).
  6. Créer un plugin : dossier SDK (en-tête C shaderixel_plugin.h, exemples, LISEZMOI_Plugins.md). Un plugin natif ajoute commandes, fenêtres, outils et opérations (utilisables par l'assistant IA et les actions) ; un plugin script lance un programme qui pilote Shaderixel.

Paint 3D : masques et matériaux intelligents

  1. Calques 3D > « + Intelligent » : matériaux en plusieurs couches qui suivent la forme du modèle (métal peint usé, fer rouillé, plastique sale, bois verni usé, cuivre oxydé, chrome poussiéreux, caoutchouc usé, pierre moussue, peinture militaire, or patiné). Ajoutez les vôtres en JSON dans library/smartmaterials.
  2. Dossiers : « + Dossier » range le calque 3D sélectionné dans un dossier (visibilité, opacité, fusion et masque communs, masque intelligent possible) ; « Entrer dans le dossier au-dessus », « Sortir du dossier », « Dégrouper ».
  3. « + Intelligent » ouvre la grille des matériaux intelligents avec leur aperçu ; un clic l'applique. En bas de la grille, « Enregistrer » range les calques de matériau actuels (valeurs, masques intelligents, liens « suit un calque ») comme nouveau matériau intelligent de votre bibliothèque, avec l'aperçu de la vue 3D ; il s'applique ensuite à n'importe quel modèle.
  4. Calque de matériau sélectionné > Masque intelligent : usure des arêtes, saleté des creux, poussière (direction), dégradé, occlusion, bruit, parties fines, suit un calque (dessus, bord, autour ou ailleurs que la peinture d'un autre calque 3D, mis à jour quand on y peint, comme les points d'ancrage de Substance) ; couverture, contraste, bruit 3D (sans raccord), échelle, graine, inverser. « Peindre des retouches » : le pinceau ajoute le matériau, la gomme l'enlève, et ces retouches restent quand le masque est recalculé (« Effacer les retouches » rend la main au masque). Les réglages sont gardés dans le .sx3d.
  5. Les cartes du maillage (occlusion, convexité, concavité, épaisseur) sont cuites en arrière-plan (moins d'une seconde pour un modèle courant) ; Vue 3D > liste des canaux > « Carte : ... » pour les voir.
  6. Vue 3D : exposition, fil de fer.

Paint 3D : cuisson, simulation et rendu (à la Marmoset)

  1. Cuisson des cartes (Vue 3D > « Cuire... » ou Fichier) : depuis le modèle du projet, ou depuis un modèle haute définition (OBJ / FBX / glTF superposé) projeté sur ses UV avec une cage (au-dessus / en dessous) : normale en espace tangent (convention DirectX / Unreal), occlusion ambiante, courbure, épaisseur, hauteur, position, normale monde ; 512 à 4096 px, rayons d'occlusion, marge. Les calques « Normale cuite » et « Occlusion cuite » vont dans les canaux, les masques intelligents suivent le détail cuit, export PNG possible.
  2. Carte d'ID (Cuisson, « ID couleur ») : une couleur unie par pièce, par matériau ou par île UV (du modèle haute définition s'il y en a un) dans un calque caché « ID cuit » et en PNG, pour sélectionner ces zones (baguette magique, plage de couleurs).
  3. Matériau projeté (Calques 3D > + Matériau > Matériau projeté) : une image qui se répète (fichier ou motif de la bibliothèque) projetée sur le modèle selon les trois axes, sans raccord d'UV : couleur, rugosité et relief tirés de l'image ; échelle, rotation, netteté des raccords, décalage. Il garde un masque : peignez-le ou ajoutez un masque intelligent.
  4. Pochoir (Matériau du pinceau > Projection > « Pochoir ») : l'image reste à l'écran et le pinceau ou la gomme ne peignent qu'à travers elle (transparence ou luminosité avec seuil et contraste pour un pochoir franc, inversion) ; S + glisser la déplace, Ctrl / Maj + molette : taille / rotation.
  5. Filtres d'un calque 3D (Calques 3D > calque sélectionné > « + Filtre ») : teinte / saturation, luminosité / contraste, niveaux, courbes, balance des couleurs, flou, netteté, bruit, inverser, sur un canal ou tous, non destructifs et réglables.
  6. Débruitage du lancer de rayons (Vue 3D et onglet Rendu) : image propre en quelques échantillons ; il s'appuie sur la couleur, la normale et la distance des surfaces vues, donc les détails des textures et les contours restent nets ; il s'efface à mesure que l'image s'affine.
  7. Export des textures (Vue 3D > « Exporter les textures... ») : modèles Unreal (ORM), Unity HDRP, Unity URP, glTF / Blender, Godot, textures séparées, avec le contenu de chaque canal affiché ; PNG 8 ou 16 bits, TGA, taille, convention de normale (DirectX / OpenGL), marge autour des îles UV, nom des fichiers.
  8. Simulation de peinture (outil Simulation, avec Projection) : en maintenant le clic, des particules partent du pinceau et peignent le matériau du pinceau là où elles passent, même derrière le modèle : coulures, ruissellement épais, poussière qui tombe, éclaboussures, propagation de taches, suie qui monte ; réglages dans Matériau du pinceau (débit, taille, gravité, adhérence, durée de vie).
  9. Ray tracing dans la Vue 3D (liste de qualité de la Vue 3D) : lancer de rayons progressif comme dans Marmoset (reflets, ombres douces, lumière indirecte, sol pour les ombres portées), avec l'HDRI de la vue ou le studio, la lumière principale en soleil et les effets de caméra. L'image s'affine quand rien ne bouge et suit la peinture en direct ; échantillons, rebonds et sol dans « Rendu et caméra... ».
  10. Pipette 3D : outil Pipette, clic sur le modèle : sa couleur, sa rugosité, son métal et sa hauteur à cet endroit passent dans le matériau du pinceau.
  11. Maj + clic droit glissé dans la Vue 3D : l'éclairage (HDRI et lumières) tourne autour du modèle, la caméra ne bouge pas. Dans Calques 3D, Alt + clic sur la case de visibilité affiche le calque seul (encore : tous).
  12. Environnements intégrés (bouton HDRI de la Vue 3D, et onglet Rendu) : studio photo, ciel couvert, plein soleil, coucher de soleil, néons, ou un fichier HDR ; l'environnement de la vue est enregistré avec le projet.
  13. Éclairage (« Rendu et caméra... ») : préréglages Simple, Studio 3 points, Contre-jour, Doux, Dramatique, Coucher de soleil, et jusqu'à 4 lumières supplémentaires (direction, hauteur, couleur, intensité, attachées à la caméra ou fixes), dans la vue rapide, qualité et en ray tracing.
  14. Profondeur de champ (ray tracing, « Rendu et caméra... ») : ouverture et distance nette ; « Choisir sur le modèle » puis un clic sur le point qui doit être net.
  15. Caméras : « + Enregistrer la vue » garde l'angle, le cadrage et la focale ; un clic sur une caméra y revient en douceur. Réglage de la focale (champ). Enregistrées avec le projet, comme les lumières.
  16. Turntable... (barre de la Vue 3D) : le modèle fait un tour complet, exporté en vidéo MP4, en GIF animé (en boucle, 720 px de large au plus) et / ou en images PNG (nombre d'images, images par seconde, taille jusqu'à 4K, échantillons par image en ray tracing). « Éclairage fixe » : lumières et HDRI tournent avec la caméra, comme un plateau tournant.
  17. Rendu : « Rendu qualité » ajoute l'ombre de la lumière principale, l'occlusion cuite l'ombre au sol (ombre portée et ombre de contact sur un sol invisible, case « Ombre au sol ») et l'occlusion d'écran (SSAO : creux et contacts assombris en temps réel, sans cuisson) ; « Rendu et caméra... » règle la lumière (suit la caméra ou fixe, direction, hauteur, soleil avec un HDRI) et les effets de caméra : exposition, courbe (ACES, AgX, PBR Neutral...), bloom, netteté, aberration chromatique, température / teinte, contraste, saturation, vignettage, grain, avec des préréglages (studio produit, cinéma, jeu vidéo, vintage). Les mêmes effets s'appliquent au rendu par lancer de rayons (onglet Rendu, réglages) et à son export PNG ; ils sont enregistrés avec le projet.

Fichiers Unreal (.uasset)

  1. Textures (.uasset de projets UE 4.x à 5.8, éditeur ou cookées, BC1 à BC7) : Fichier > Ouvrir, glisser-déposer sur le canevas / le graphe (objet dynamique ou nœud image), comme une image. Oodle est chargé depuis votre installation d'Unreal si besoin.
  2. Maillages (StaticMesh, SkeletalMesh) : glissez-les dans l'onglet Rendu, ouvrez-les (nouveau projet Paint 3D) ou choisissez-les dans « + Modèle... ». La version d'Unreal du projet les exporte en arrière-plan (sans fenêtre, le Content est monté en lecture seule), avec la texture de couleur et la rugosité / le métal de leurs matériaux ; le résultat est gardé en cache.
  3. Le .uasset doit rester dans le dossier Content de son projet (à côté du .uproject) ; la première conversion d'une version d'Unreal prend un peu plus de temps.

Plugin Unreal Engine (Shaderixel Link)

  1. Copiez Unreal/<version>/ShaderixelLink (4.25 à 5.8) dans le dossier Plugins de votre projet, puis activez « Shaderixel Link » (Edit > Plugins).
  2. Content Browser, clic droit sur un Static Mesh > Peindre dans Shaderixel > emplacement de matériau : un projet Paint 3D s'ouvre avec le maillage (ses UV) et les textures du matériau dans un calque « Unreal (textures d'origine) ».
  3. Peignez, puis Ctrl+S (ou « Envoyer vers Unreal » dans la barre d'état) : les textures sont réimportées en place. Case Direct à côté : envoi automatique un instant après chaque modification, le matériau se met à jour en direct dans Unreal. Sans texture au départ : nouvelles BaseColor / Normal / ORM et une instance de matériau assignée.
  4. Clic droit sur une Texture 2D > Éditer dans Shaderixel.
  5. Modèle + matériau prêts : dans Shaderixel, Vue 3D > « Unreal... » (ou Fichier > Exporter pour Unreal) règle le nom, le dossier, l'échelle (100 pour un modèle en mètres), le matériau parent, la double face et l'intensité émissive ; ces réglages sont enregistrés dans le .sx3d. L'export écrit le modèle (OBJ), les textures et une description .sxmat.json.
  6. Dans Unreal : Tools > Shaderixel > Importer un modèle Shaderixel... avec le .sxmat.json, ou directement le projet .sx3d (Shaderixel l'exporte en arrière-plan) : maillage statique SM_, textures T_ réglées (sRGB, compression), instance MI_ du matériau M_ShaderixelPBR2 (ou de votre matériau parent) déjà assignée. Commande console : Shaderixel.Import <fichier> [dossier].
  7. Un .sxmat.json posé à côté d'un FBX / OBJ du même nom est appliqué automatiquement quand vous importez ce modèle normalement dans Unreal. Les textures seules (.sxue.json) s'importent par le même menu.

Mode Rendu (path tracing)

  1. Onglet « Rendu » (à côté de la Vue 3D d'un projet .sx3d) : le modèle peint est rendu en path tracing progressif ; l'image s'affine au fil des échantillons. Clic gauche / droit : orbite, molette : zoom, clic molette : déplacer.
  2. Calcul GPU par défaut (toute carte graphique : NVIDIA, AMD, Intel) ou CPU (tous les cœurs, même résultat). Pause, Recommencer, « Exporter l'image... » en PNG, JPEG ou HDR (Radiance, valeurs linéaires). « Exporter les passes... » : l'image et ses passes pour le compositing (albédo, normales, profondeur, masque de couverture).
  3. Glissez-déposez dans l'onglet Rendu un modèle (.obj avec son .mtl, .fbx, .gltf / .glb) ou un projet Paint 3D (.sx3d) : il rejoint la scène, posé au sol, avec ses matériaux (un par partie, texture de couleur comprise) ou ses textures peintes. Aussi par « + Modèle... ».
  4. Panneau « Scène de rendu » (onglet 3D) : objets (sol, fond cyclo, cube, sphère, maillages OBJ / FBX / glTF importés, projets .sx3d, copies du modèle) avec position, rotation, échelle et matériau (préréglages, verre, métal, émission) ; lumières ponctuelles, spots, surfaciques et soleil ; environnement studio intégré ou fichier HDRI (intensité, rotation, visible en fond).
  5. Caméra : champ de vision, profondeur de champ (ouverture, mise au point) ; réglages : échantillons, rebonds, taille de la vue ou résolution fixe (jusqu'à 8K), exposition, courbe ACES / Reinhard. La scène est enregistrée dans le .sx3d.

Scènes de rendu

  1. La scène (objets, matériaux, lumières, HDRI, réglages, caméra) est enregistrée avec le projet .sx3d ; les fichiers dans le dossier du projet sont notés en chemins relatifs.
  2. Panneau « Scène de rendu » > Scène : préréglages (Studio doux, Studio trois lumières, Produit sur fond noir, Extérieur ensoleillé, Contre-jour dramatique, Sol réfléchissant) appliqués en entier, pour l'éclairage et l'environnement seulement, ou pour ajouter leurs objets ; les positions suivent le sol du projet.
  3. « Enregistrer la scène... » / « Charger une scène... » : un fichier .sxscene réutilisable dans d'autres projets ; « Enregistrer comme préréglage » l'ajoute à la liste.
  4. « Rassembler les fichiers » : les modèles importés (avec .mtl, textures, .bin ; un maillage Unreal sous sa forme convertie) et le HDRI sont copiés dans « <projet>_fichiers » à côté du projet, qui reste complet si les originaux bougent ou si vous l'envoyez. Les fichiers introuvables sont signalés en rouge.

Éditeur d'effets et graphes

  1. « ◀ Bibliothèque » : effets, fusions et pinceaux avec recherche ; « Nouveau à partir de ce modèle » (copie) ou « Éditer l'original » (après déverrouillage). « Annuler les modifications » revient à l'état et au panneau d'avant.
  2. Palette de nœuds (onglet Effets) : glissez un nœud sur le graphe des calques ou sur le graphe d'effet, ou cliquez pour l'ajouter au centre.
  3. Glissez une image depuis l'explorateur sur le graphe, le canevas ou les calques : en mode calques, elle arrive à sa taille réelle comme objet dynamique (Ctrl+T la transforme sans perte) ; en mode nodal, un nœud image suivi d'un nœud Transformation (position, échelle, rotation, pivot), fusionné au résultat. Ailleurs, elle s'ouvre comme document.
  4. Cliquez un nœud d'effet dans le graphe (mode calques) : ses paramètres s'affichent en haut de Propriétés (« Filtre : ... ») et se règlent directement ; les autres réglages du calque sont repliés dans « Calque : ... ». Cliquer le calque dans Calques revient à ses propriétés.
  5. Barre d'état : Vue finale / calque seul / jusqu'au calque (Ctrl+Alt+1 2 3).

Retouche et déformation

  1. Sélectionnez un objet puis Édition > Remplir d'après le contenu (Maj+F5) : la zone est reconstruite depuis le reste de l'image, sans IA.
  2. Groupe du correcteur (J, Maj+J pour changer) : Pièce, Déplacement basé sur le contenu, Yeux rouges. Gommes (Maj+E) : gomme d'arrière-plan, gomme magique. Forme d'historique (Y) : instantané dans le panneau Historique.
  3. Édition > Marionnette (épingles) et Déformation de la perspective (plans, puis « Déformer »).

Photo

  1. Ouvrez un RAW : tous les formats d'appareils photo sont décodés par LibRaw (CR2, CR3, CRW, NEF, NRW, ARW, RAF, ORF, RW2, PEF, DNG, X3F, 3FR, IIQ...), en 32 bits linéaire, balance des blancs de l'appareil, sans courbe ajoutée. La fenêtre Photo RAW s'ouvre aussitôt.
  2. Filtre > Photo RAW... (Ctrl+Maj+A) sur n'importe quel calque : grand aperçu (molette ou double-clic pour zoomer, glisser pour se déplacer), histogramme, Avant (P). Sections : Base (balance des blancs, exposition, contraste, hautes lumières, ombres, blancs, noirs, texture, clarté, correction du voile, vibrance, saturation), Courbe des tonalités, Détail (netteté, réduction du bruit de luminance et de couleur), Mélangeur de couleurs (teinte / saturation / luminance par couleur), Étalonnage des couleurs (ombres, tons moyens, hautes lumières, équilibre), Optique, Effets (vignettage, grain). OK = une seule étape d'historique ; Annuler revient à l'état d'avant. Les réglages restent modifiables : c'est le filtre Photo RAW du calque (bouton « Ouvrir dans Photo RAW... » dans Propriétés).
  3. Photo RAW : Pipette (W) puis clic sur une zone neutre pour la balance des blancs ; « Balance auto », « Tel quel » (balance de l'appareil), « Auto » (balance, exposition, hautes lumières, ombres, blancs et noirs calculés sur l'image). Préréglages : Vif, Paysage, Portrait doux, Noir et blanc, Film délavé, Tons chauds / froids, Teal & orange, Haute / basse clé... ; « Enregistrer... » crée les vôtres (avec ou sans balance et exposition, clic droit pour supprimer). « Copier » / « Coller » reporte les réglages d'une photo sur une autre.
  4. Géométrie (section Optique de Photo RAW, ou Filtre > Déformation > Géométrie) : perspective verticale (verticales des bâtiments qui convergent quand l'appareil est incliné), perspective horizontale, rotation pour redresser l'horizon, aspect, échelle, décalage ; « Remplir le cadre » zoome juste assez pour ne pas laisser de bords vides, « Afficher une grille » aide à aligner. « Avant » (P) coupe aussi la géométrie et les retouches locales.
  5. Retouches locales (section de Photo RAW) : « + Filtre gradué » (effet plein au point A, nul au point B : ciel, premier plan) et « + Filtre radial » (ellipse : visage, sujet ; « Inverser » pour agir autour). Déplacez les poignées sur l'aperçu (point rouge : A / centre ; poignée du milieu : tout le dégradé ; poignées de l'ellipse : rayons), réglez température, teinte, exposition, contraste, hautes lumières, ombres, blancs, noirs, saturation, voile et une couleur ajoutée. « Afficher le masque » montre la zone en rouge. Chaque retouche est un filtre « Retouche locale » du calque, modifiable ensuite.
  6. Développer par lots : dans Photo RAW, « Lot... » > « Traiter un dossier de RAW avec ces réglages... » crée une action « Photo RAW - <photo> » (étape Photo RAW (développement) : vos réglages, la correction d'objectif d'après les métadonnées de chaque photo, et en option la balance et les tons automatiques par image) et ouvre le Traitement par lots en JPG : choisissez le dossier, Démarrer. L'étape s'ajoute aussi à vos actions depuis l'éditeur d'actions.
  7. Export TIFF 16 bits (Fichier > Exporter..., type « TIFF 16 bits », étape Exporter des actions, format de sortie du traitement par lots) : 16 bits par couche, compression sans perte (deflate), transparence gardée si l'image en a ; idéal après un développement RAW.
  8. Panneau Ressources : les RAW ont une vignette (aperçu intégré au fichier), avec leurs dimensions et le boîtier.
  9. Correction d'objectif (lensfun) : téléchargez la base de profils lensfun (fichiers XML du dossier data/db du projet lensfun, bouton « Page de téléchargement ») et placez-les dans %LOCALAPPDATA%\Shaderixel\lensfun (« Ouvrir le dossier », puis « Recharger » ; ou « Choisir un autre dossier... » ; une installation darktable / RawTherapee est détectée). Dans Optique, cochez « Activer les corrections de profil » : l'objectif est retrouvé d'après les métadonnées de la photo (sinon cherchez-le dans la liste), focale, ouverture, distance et crop du boîtier ajustables ; distorsion, aberrations chromatiques et vignetage corrigés, « Remplir le cadre » recadre les bords courbés.
  10. Simuler un objectif : Filtre > Déformation > Correction d'objectif sur n'importe quel calque, mode « Simuler l'objectif », choisissez l'objectif dans la liste lensfun des Propriétés : sa distorsion, ses aberrations chromatiques et son vignetage sont appliqués à l'image (par exemple un 10 mm grand-angle sur un rendu 3D). Les paramètres restent réglables à la main (modèles poly3 / poly5 / ptlens) et l'intensité de chaque défaut est dosable.
  11. Fichier > Automatisation > Photomerge (panorama) ou Fusion HDR. Édition > Alignement / Fusion automatique des calques (panorama ou empilement de mise au point).
  12. Couleur : Affichage > Épreuvage (Ctrl+Alt+Y), Image > Mode (RVB, CMJN, Lab), Édition > Attribuer / Convertir en profil, Fichier > Exporter en TIFF CMJN.

Productivité et ressources

  1. Onglet Outils > Actions : « Enregistrer », utilisez les menus (taille, filtres, rotation...), « Arrêter », puis « Exécuter » ou « Traitement par lots... » sur un dossier.
  2. Fichier > Automatisation > Éditeur d'actions (ou « Éditeur... » dans le panneau Actions) : chaque étape est expliquée en clair ; cochez / décochez, glissez pour réordonner, clic droit pour exécuter une étape, jusqu'ici ou à partir d'ici ; réglages complets à droite (JSON en avancé). « Actions simples » : conversions (PNG, JPG, TGA, BMP, PSD, SXL), tailles, carré centré, 16:9, rotations, noir et blanc, vignettes ; « Copier dans mes actions » pour les modifier. Import / export en .sxactions.
  3. Ouvrir en grand : l'icône (deux fenêtres) en haut à droite des panneaux Effets, Fusions, Calques, Graphe, Ressources (textures et modèles 3D), Palette de nœuds, Matériaux, Pinceaux, Motifs, Trim sheet et des éditeurs ouvre le panneau dans une grande fenêtre séparée (sur le 2e écran s'il y en a un) ; la même icône le rattache. Aussi F11 sur le panneau sous la souris, ou Fenêtre > Ouvrir en grand.
  4. Traitement par lots : enchaînez plusieurs actions, source = dossier (sous-dossiers, filtre d'extensions) ou documents ouverts, format de sortie (ou même format que l'original), qualité JPG, noms avec {nom} {n3} {l} {h} {date}, sous-dossiers recréés, fichiers existants remplacés / ignorés / numérotés. Aperçu des noms avant de lancer, journal cliquable ensuite.
  5. Compositions de calques, plans de travail (Calque > Nouveau plan de travail ; Fichier > Exporter les plans de travail), styles de texte (caractère et paragraphe), texte sur tracé (cliquez sur un tracé avec l'outil Texte).
  6. Déposez un .abr (pinceaux), .pat (motifs), .aco / .ase / .gpl (nuanciers) sur la fenêtre. Panneaux Nuancier et Motifs dans l'onglet Peinture ; outil Tampon de motif avec le tampon (S).
  7. Formes : avec l'outil Forme sur un calque de forme, Maj unit, Alt soustrait, Maj+Alt intersecte (liste dans Propriétés).

4. Grands formats

  1. Nouveau document 16384 × 16384.
  2. Le rendu passe en tuiles (barre de progression en bas) et les calques n'occupent la mémoire que là où vous peignez.
  3. La barre d'état indique la VRAM utilisée.

IA optionnel

Inpainting IA

  1. Panneau « Inpainting IA » (onglet IA) : cochez « Peindre le masque » ; le pinceau peint la zone à régénérer (teinte rose sur le canevas), la gomme la retire. Ou « Depuis la sélection », « Inverser », « Effacer ». Le masque est gardé avec le document.
  2. Écrivez le prompt, choisissez le fournisseur : ComfyUI (graphe d'inpainting intégré avec le modèle des réglages IA, Denoise pour une retouche plus légère, ou votre workflow API), OpenAI, Gemini, ou « Test local » pour essayer sans réseau.
  3. « Générer » : la zone et son contexte partent avec le masque ; le résultat arrive sur un nouveau calque dont le masque est la zone agrandie et adoucie (réglages Agrandir / Adoucir) : il se fond dans l'image, rien n'est écrasé. Avec plusieurs variations, cliquez sur leurs vignettes pour les comparer sur le calque.

Génération et remplissage génératif

Panneau Génération IA : définissez la variable d'environnement de clé (OPENAI_API_KEY ou GEMINI_API_KEY) avant de lancer l'application. Le remplissage génératif remplace la zone sélectionnée sur un nouveau calque masqué.

Sans clé, testez la chaîne avec set SX_AI_MOCK=1 avant de lancer : un résultat factice local est utilisé.

ComfyUI (local) : choisissez ce fournisseur, indiquez l'adresse du serveur (http://127.0.0.1:8188 par défaut) et soit un checkpoint pour le graphe intégré, soit un workflow exporté avec « Save (API format) » : le prompt, la graine, la taille et l'image actuelle (option img2img) y sont injectés.

Pont MCP (CyToolsCore)

Panneau Assistant IA : le pont local est actif au lancement ; « Autoriser l'IA à modifier le document » pour les opérations d'écriture. Un agent externe peut piloter Shaderixel (calques, effets, export).

Limites connues

  • Les appels réels aux fournisseurs IA n'ont pas pu être testés sans clé ; les scripts Unreal générés n'ont pas été exécutés dans Unreal.
  • Les interactions stylet/souris des outils récents (plume, sélection rapide, repères) ont été vérifiées par scripts ; vos retours sont précieux.
  • Le fichier shaderixel.log à côté de l'exécutable aide à diagnostiquer un problème.
